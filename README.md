# s8int

I build Windows tools for field work, files and everyday tasks. My main focus is HFC software: working from PDF plant drawings, reviewing equipment and keeping useful field records.

- **HFC Field Tracker** scans PDF equipment maps, keeps a reviewed work list and exports marked drawings.
- **HFC Setup Assistant** records meter readings and checks them against editable work targets.
- **Informent Hub** brings the tools together with project previews, verified downloads and updates.
- **Keydock** manages owner-issued licenses and access to the current releases.

The [project catalog](https://github.com/informent/Projects) includes the HFC tools, Framecraft, UploadFit and the rest of the collection. Current application source and owner releases are private. Protected builds require a key issued by me.
