## Projects

Windows tools have an installer and a portable download. Source, setup notes, and release history are in each repository.

### Files and everyday use

- **[Savepoint](https://github.com/informent/Savepoint)**: Back up and compare PC game saves. [Releases](https://github.com/informent/Savepoint/releases)
- **[Courier](https://github.com/informent/Courier)**: Transfer files over a local network and verify receipts. It is a preview release; testing between two physical computers is pending. [Releases](https://github.com/informent/Courier/releases)
- **[Batchwork](https://github.com/informent/Batchwork)**: Preview and recover batch file renames. [Releases](https://github.com/informent/Batchwork/releases)
- **[Footprint](https://github.com/informent/Footprint)**: Inspect disk usage and export CSV reports. [Releases](https://github.com/informent/Footprint/releases)
- **[Cliptray](https://github.com/informent/Cliptray)**: Keep clipboard history on your device, with deletion and secret filters. [Releases](https://github.com/informent/Cliptray/releases)

### System and developer tools

- **[Checkup](https://github.com/informent/Checkup)**: Collect Windows troubleshooting reports. [Releases](https://github.com/informent/Checkup/releases)
- **[Rackwatch](https://github.com/informent/Rackwatch)**: Inspect Windows servers and local ports. [Releases](https://github.com/informent/Rackwatch/releases)
- **[Packbench](https://github.com/informent/Packbench)**: Package desktop projects and check ZIP contents. [Releases](https://github.com/informent/Packbench/releases)
