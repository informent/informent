## OpenDesk

[OpenDesk](https://github.com/informent/OpenDesk) is a free, open-source Discord bot for moderation, tickets, roles and community features. It is under active development and currently available as a source prerelease. Live Discord validation is still pending.

[Commands](https://github.com/informent/OpenDesk/blob/main/COMMANDS.md) | [Setup](https://github.com/informent/OpenDesk#start-here) | [Releases](https://github.com/informent/OpenDesk/releases)

Each repository has its source, documentation and issue tracker. Release notes describe what changed and what was checked.
