# xnx

### Windows utilities. Self-hosted software. Open source.

I build tools for the things I spend time doing: managing files, keeping backups, running servers and maintaining Discord communities.

[Explore the projects](#projects) · [Discord bot](#latch) · [Source repositories](https://github.com/informent?tab=repositories)

## Currently building

Local file backups with snapshot comparison and restore previews. Compare file contents and export a report before restoring.

**[Latch](https://github.com/informent/Latch)**

## Latch

**Free and open source. Bring your own hosting.**

The command reference covers moderation, tickets, roles, reminders, giveaways and server utilities. Setup is guided, and the repository includes configuration checks and deployment instructions.

Latch is currently a **source prerelease**. Live Discord acceptance testing is still pending. Courier is also a preview release; physical two-computer testing is pending.

[Commands](https://github.com/informent/Latch/blob/main/COMMANDS.md) | [Setup](https://github.com/informent/Latch#start-here) | [Releases](https://github.com/informent/Latch/releases)
