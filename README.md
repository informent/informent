## Latch

**Free and open source. Bring your own hosting.**

The command reference covers moderation, tickets, roles, reminders, giveaways, public-message highlights and server utilities. Starboard history and recovery commands help staff inspect and finish interrupted operations. Setup is guided, and the repository includes configuration checks and deployment instructions.

Latch is currently a **source prerelease**. Live Discord acceptance testing is still pending. Courier is also a preview release; physical two-computer testing is pending.

[Commands](https://github.com/informent/Latch/blob/main/COMMANDS.md) | [Setup](https://github.com/informent/Latch#start-here) | [Releases](https://github.com/informent/Latch/releases)
