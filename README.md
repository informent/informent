# xnx

I came from online circles where people out of work made money through crime. I work overtime every week; outside work, I build useful free software.

I work on tools for managing files, running Windows machines and maintaining online communities. I prefer software that explains what it is about to do, keeps data local where practical, and leaves a useful record when something goes wrong.

[Projects](#projects) · [Latch](#latch) · [Repositories](https://github.com/informent?tab=repositories)

## Work in progress

**[Backstop](https://github.com/informent/Backstop)** is a Windows backup utility. It compares snapshots and lets you inspect a restore before applying it.

[Releases](https://github.com/informent/Backstop/releases) · [Source and documentation](https://github.com/informent/Backstop)

**[Latch](https://github.com/informent/Latch)** is a free, self-hosted Discord bot for moderation, tickets, roles and community tools.

## Latch

Latch is source-only and self-hosted. It has moderation, tickets, roles, reminders, giveaways, highlights and server utilities. Its command reference and setup instructions are in the repository.

Live Discord acceptance testing is still pending. Courier is a preview release; testing between two physical computers is pending.

[Commands](https://github.com/informent/Latch/blob/main/COMMANDS.md) · [Setup](https://github.com/informent/Latch#start-here) · [Releases](https://github.com/informent/Latch/releases)
